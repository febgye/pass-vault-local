# LiquidVault

Windows 本地加密保险库。密码、笔记、聊天记录、文本和文件附件全部加密保存在本地 `.lvault` 文件中。无需网络，不需要账户。

## 主要特性

- 密码、私密笔记、聊天记录、通用文本四种资料类型。
- 每个条目支持多个加密附件。
- 文件可以通过选择器添加，也可以直接拖入密码库。
- 拖入主界面的文件会自动创建独立的文件条目。
- 图片和纯文本可以在密码库内直接查看。
- Argon2id 主密码强化，兼容 PBKDF2-SHA-256 模式。
- AES-256-GCM 加密，锁定状态下隐藏标题、账号和正文。
- 跨进程独占锁，防止多个实例同时修改同一保险库。
- 临时文件完整验证后原子替换，自动轮换最近 5 个历史备份。
- 无网络、无云同步、无账户。
- 中文界面。

## 安全声明

详细内容见 [SECURITY.md](SECURITY.md)。这里只列最重要的事实：

- 数据只保存在本机。
- 忘记主密码无法恢复。
- 不能防御已获得本机管理员权限的恶意软件。
- 不保证 SSD 删除等于物理不可恢复。
- 使用前请先完成测试并保留经过验证的加密备份。

## 文件附件

- 文件导入后，原文件会从电脑上删除。
- 文件内容加密保存在 `.lvault` 中。
- 从密码库删除文件条目时，文件会恢复到原始位置。
- 图片和纯文本可以直接在密码库内查看。
- 单个附件限制 16 MiB。
- 单个保险库限制 64 MiB。

支持的图片格式：`.png`、`.jpg`、`.jpeg`、`.gif`、`.bmp`、`.webp`。

支持的文本格式：`.txt`、`.csv`、`.json`、`.xml`、`.md`、`.log`。

## 构建

需要：

- Windows 10 1809 或更高版本，推荐 Windows 11。
- Visual Studio 2026 Community，安装“WinUI 应用开发”工作负载。
- .NET 10 SDK。

命令行构建：

```powershell
dotnet build -c Release
dotnet run --project tests/LiquidVault.SelfTest -c Release
```

首次构建需要联网从 NuGet 获取 Windows App SDK 和 Argon2id 依赖。

## 从旧版迁移

1. 在旧版 HTML 版本中导出 v5 加密备份。
2. 启动 LiquidVault，选择“从旧版 v5 加密备份迁移”。
3. 选择 JSON 备份并输入旧主密码。
4. 选择新 `.lvault` 保存位置并设置新主密码。

迁移完成后，程序会验证格式、密钥 verifier、HMAC 和逐条 AES-GCM 解密；旧备份不会被修改。

## 参与开发

- 不提交任何 `.lvault`、`.lvault.bak` 或真实数据。
- 使用一次性测试保险库进行测试。
- 保证自测全部通过。
- 保持安全相关行为不变，修改密码学相关代码时需要额外说明。

## 使用边界

- 忘记主密码后无法恢复。
- 解锁状态下，已控制本机的恶意程序、管理员级调试器或键盘记录器仍可能读取明文。
- Windows 剪贴板历史及第三方剪贴板工具可能保留此前复制的内容。
- 截屏保护是隐私缓解措施，不是对所有截屏方式的绝对防护。
